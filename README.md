## 🧠 About me

- 🐟 Computer Vision Engineer at **Fabrimaq SpA** (Puerto Montt, Chile), building real-time fish counting and biomass estimation systems running at production aquaculture sites.
- ⚙️ I own the whole pipeline: dataset curation & labeling → training (Ultralytics YOLO) → TensorRT INT8 optimization → multi-object tracking (ByteTrack) → industrial GigE camera integration → on-site deployment.
- 🚀 Currently working on real-time detection pipelines at 100+ FPS.
- 🏆 1st place at **Duckie Day** (Duckietown robotics competition) — 2025 and 2026 editions.
- 🎓 Final-year Computer Engineering (Ingeniería en Informática) student at Duoc UC.
- 📊 Beyond vision: data analytics, dashboards and applied machine learning.
- 💼 Open to freelance computer vision & ML projects.
